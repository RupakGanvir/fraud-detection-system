# IEEE-CIS Fraud Detection System

## Overview

Machine learning system for detecting fraudulent transactions using the IEEE-CIS Fraud Detection dataset.

## Dataset

- 590,540 transactions
- Severe class imbalance (~3.5% fraud)

## Techniques Used

- Exploratory Data Analysis
- Feature Engineering
- Logistic Regression (NumPy)
- SMOTE
- XGBoost
- Geospatial Visualization
- FastAPI
